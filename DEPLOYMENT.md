# Deployment Guide (Free Tier, No Credit Card)

## Step 1: Set Up Neon.tech PostgreSQL (Free)

1. Go to https://neon.tech and sign up (no credit card needed)
2. Create a new project:
   - Project name: `nazmul-ecommerce`
   - Database name: `nazmul_ecommerce`
   - Region: closest to your users
3. Copy the connection string from the dashboard:
   ```
   postgres://username:password@ep-xxx.us-east-2.aws.neon.tech/nazmul_ecommerce?sslmode=require
   ```

## Step 2: Deploy to Render.com (Free)

1. Go to https://render.com and sign up with GitHub
2. Click **New** → **Blueprint** (or **New** → **Web Service**)
3. Connect your GitHub repo: `nazmulnabil/django-ecommerce-api`
4. Select the branch: `feature/catalog-api-docker`
5. Render will auto-detect `render.yaml` and configure:
   - Web service: `nazmul-ecommerce-api`
   - Database: `nazmul-ecommerce-db`
6. **Important**: Override the `DATABASE_URL` env var with your Neon.tech connection string
7. Deploy

## Step 3: Run Seed Data

After deployment, open the Render shell (Dashboard → Web Service → Shell) and run:

```bash
python manage.py seed_catalog
```

This creates:
- 12 products across 3 categories
- 30+ variants with images
- 2 warehouses with inventory

## Step 4: Access Your App

- **API Root**: `https://nazmul-ecommerce-api.onrender.com/api/v1/`
- **API Docs**: `https://nazmul-ecommerce-api.onrender.com/api/docs/`
- **Admin**: `https://nazmul-ecommerce-api.onrender.com/admin/`

## Step 5: Seed Data Login

- **Admin**: Create a superuser via shell or use the seller account
- **Seller**: `seller@example.com` / `seller1234`

## Environment Variables

| Variable | Value | Notes |
|----------|-------|-------|
| `SECRET_KEY` | Auto-generated by Render | Never commit this |
| `DEBUG` | `false` | Production mode |
| `DATABASE_URL` | Neon.tech connection string | Override in Render |
| `DJANGO_SETTINGS_MODULE` | `config.settings.production` | Set by render.yaml |
| `ALLOWED_HOSTS` | `.onrender.com` | Allows Render domains |
| `CORS_ALLOWED_ORIGINS` | Your frontend URL | Add when frontend is deployed |

## Troubleshooting

**App won't start?**
- Check logs in Render dashboard
- Ensure `DATABASE_URL` is set correctly
- Verify migrations ran: check Render shell output

**502 Bad Gateway?**
- App might be sleeping (free tier)
- First request takes ~30s to wake up
- Check if `gunicorn` is running correctly

**Database connection failed?**
- Ensure Neon.tech database is active
- Check connection string format
- Verify SSL mode: `?sslmode=require`
